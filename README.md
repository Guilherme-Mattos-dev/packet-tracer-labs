# Packet Tracer Labs

Laboratórios de redes feitos no Cisco Packet Tracer. Cada pasta é um projeto, com o arquivo `.pkt`, os prints e um relatório (`README.md`) explicando o que foi montado, configurado e testado.

## Laboratórios

| # | Projeto | Assunto | Status |
| --- | --- | --- | --- |
| 01 | [Rede local básica](01-rede-basica/) | Endereçamento IP, ping, ARP e modo Simulation | Concluído |
| 02 | VLANs e trunk | Separar a rede em grupos lógicos | Planejado |
| 03 | Roteamento entre redes | Roteador e gateway | Planejado |
| 04 | DHCP e DNS | IPs automáticos e acesso por nome | Planejado |
| 05 | Rotas estáticas e OSPF | Roteamento entre vários roteadores | Planejado |
| 06 | ACLs e segurança | Controle de tráfego e proteção de portas | Planejado |
| 07 | NAT e projeto final | Saída para a "internet" e rede integrada | Planejado |

## Como abrir um laboratório

1. Instale o Cisco Packet Tracer (gratuito pela Cisco Networking Academy).
2. Baixe o arquivo `.pkt` da pasta do laboratório.
3. Abra o arquivo no Packet Tracer e leia o `README.md` da mesma pasta para seguir o roteiro.
